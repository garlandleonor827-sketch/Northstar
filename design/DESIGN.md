# 视觉与交互规范
合同已确认方向：**商务精致的私人战略指挥室＋宇宙天体/抽象生命感核心**。

## 视觉基线
- 深色默认：黑钛底、分层烟熏玻璃、细边线、少量冰蓝和冷白银。不要满屏彩色HUD、粉紫渐变或廉价金属贴图。
- 浅色：冷白底、银灰面、深蓝强调，重新设计Core承托场；不是把深色反相。
- tokens.json 是机器可读设计值；截图是排版/材质方向，文案与业务必须真实组件实现。
- 标准参考画布1600×1000；主区域最低1024×720，1280×800必须无横向页面滚动。
- 侧栏208px，可收至72px；主内容边距32px，内容间距24px。Today的行动区约60%，Core区约40%。
- 今日首要事项28–32px；正文14–16px；次要标签12px。不用整页10px细灰字换“高级感”。
- 中文系统字栈：Segoe UI, Microsoft YaHei UI, Noto Sans CJK SC, sans-serif；数字tabular-nums。不分发字体。
- 面板圆角16px，控件10px；描边1px，阴影低对比。真实玻璃限局部，文字下面不能有噪点干扰。

## 首屏层级
1. 顶栏：面包屑/日期、轻量连接状态、主题开关、快捷命令。
2. 左主区：今日一句首要行动 → 开始/记录 → 最多3个关键动作 → 本周成果。
3. 右主区：Core无厚重容器 → Stage与可解释状态 → “进入战略会话”。
4. 底部：最多一条可操作建议及依据。详细统计、财务、成长数字放侧栏或下层。
AI会话展开为右侧约520px的工作区，左侧今日内容仍可定位；1024px时改为独立页面，不挤成三列。

## Core构成与状态
中心是不规则折面/流形能量体；外围2–4条稀疏轨道，少量发光节点；远场光晕要薄，不堆烟雾。
材质：低粗糙度银钛＋透光冷蓝，亮部保留细节。不要正面像眼睛的造型，也不要通体线框地球。
assets/core为合成静态降级图；实时实现依据该方向重新建程序化几何，不要求逐像素拟合。

| 状态 | 表现 | 数据来源 |
|---|---|---|
| Focused | 小幅稳定呼吸，轨道低速协调 | 用户开启专注/当前有效计划 |
| Drifting | 轨道相位轻微偏移；旁边有文字依据 | 经过确认的主线偏移信号 |
| Overloaded | 光场略收束、提示减量，不高频闪烁 | 排程超容量等可计算冲突 |
| Recovering | 更慢、更安静，暖化银色但不变脏 | 用户恢复模式 |
| Dormant | 降低运动，仍保留形态 | 无交互/窗口空闲 |
| Unknown | 中性静态，不暗示“懒惰” | 数据不足 |
API等待、输出、报错覆盖层单独管理；不能把网络错误变为用户退化。

## 成长与动画
7阶段从少量结构到更丰富的内外层；Ⅰ–Ⅲ先完成可区分几何，Ⅳ–Ⅶ参数可扩展但不得只是放大亮度。
常规过渡160–240ms，呼吸周期7–10s；日常低速，专注时更克制。
战略确认/进化允许2–4s仪式动画，提供跳过；启用减少动效则瞬时或短淡入。
不要求进化按季度定时发生；由core-rules.json的证据事件决定，可在详情解释。
默认无音效；后期声音另行讨论，当前不下载音频、不用在线音源。

## 性能与无障碍门槛
标准机器目标30fps日常、关键交互可达60fps；这是待实测目标，不是本包承诺。
像素比上限1.5，透明粒子预算先256，移动层不加入MVP；性能不足减轨道/粒子/后处理。
页面隐藏停止帧循环；单个Core canvas，不为每张卡片创建WebGL上下文。
焦点可见、键盘可达、状态不只靠颜色；普通文字对比≥4.5:1，关键边界/图标≥3:1。[S5]
提供减少动效开关并尊重系统设置；动画可暂停，不使用闪烁奖励。[S6]
WebGL失败时透明图降级，并显示“静态显示”；这是合格降级，正常环境不可用它替代实时实现。

## 切图原则
UI参考图不能拿来当全屏背景或可点击热区；所有文字/按钮/任务/进度条必须真实DOM。
Core PNG/WebP可作初始化/无WebGL/减少动效状态。SVG图标可直接使用，渐变场SVG仅承托Core。
开发者应提交1600×1000深浅两张截图、1280×800缩放截图、键盘焦点和WebGL失败截图。
